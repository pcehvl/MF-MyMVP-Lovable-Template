# Worked example (fictional)

A small, **fictional** example that shows what good artefacts look like. The
product, people and quotes are invented for teaching; do not reuse them as
evidence.

| File | Shows |
|---|---|
| [`evidence/E-001-interview-student-anna.md`](evidence/E-001-interview-student-anna.md) | An evidence card: verbatim evidence kept apart from interpretation |
| [`US-000-post-a-book/spec.md`](US-000-post-a-book/spec.md) | A `ready` Story spec with `revision`, observable `ACn` and traceability |

In your own product, cards go in `docs/design-thinking/` and Stories in
`product/stories/`, numbered from `E-001` and `US-001`.
